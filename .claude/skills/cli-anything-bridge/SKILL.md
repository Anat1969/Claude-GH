# מתוכנה לפקודה, בלי MCP

==אם לתוכנה יש CLI בקטלוג, Claude מפעיל אותה בעצמו. לא מעלים קובץ לאתר.==
מקור: HKUDS/CLI-Anything (Apache-2.0, כ-59 אלף כוכבים). נבדק ב-18.11.2026 מול הריפו, ו-`cli-hub` הותקן ורץ בסביבת הענן.

## סדר פעולה
1. חיפוש בקטלוג: `pip install -q cli-anything-hub && cli-hub search <נושא>`.
2. קיים: `cli-hub install <שם>`, ואז `cli-anything-<שם> --help`. רק תוכנות שמותקנות בסביבה, או שאפשר להתקין חינם (apt, pip).
3. לא קיים ויש תוכנה בקוד פתוח: הפלאגין `/cli-anything <תיקייה>` בונה עבורה CLI בשבעה שלבים (מופעל אוטומטית דרך `.claude/settings.json`).
4. לא קיים ואין תוכנה: חוזרים לכלל בנק הכלים (ffmpeg, Playwright, סקילים מובנים).

## גבולות (שער בטיחות)
- **קוד של צד שלישי רץ אצלנו.** לפני התקנת CLI שלא ברשימה הרשמית של HKUDS: בודקים בעמוד ה-CLI מי כתב אותו ומה הוא מריץ.
- **שירותי ענן** (Zoom, Mailchimp, n8n) דורשים OAuth. בלי מפתחות בקוד, ובלי מידע עירוני או אישי החוצה. מפתח נשאל דרך הכלי המאובטח.
- **תוכנה מסחרית:** לא מתקינים. בלי תשלום.
- כל שימוש נרשם ב-`docs/tools-bank.md`, פרק CLI-Anything.

## איפה בתיק
דיאגרמות (drawio) לדפי הסבר, המרת מסמכים (libreoffice) לאפליקציות עירייה, עריכת SVG ותמונות (inkscape, gimp) לשפת העיצוב, ומודלי תלת־ממד (blender, freecad) להמחשות.
